# Simat

Simat is a digital menu platform for restaurants.

## What it is

A web app where a restaurant owner builds their menu once — in Arabic and English — and gets a permanent QR code for each branch. Customers scan the QR with their phone and instantly see the live menu: photos, prices, offers and categories, in a clean mobile design.

## What it does

- Owner manages everything from a dashboard: categories, items, photos, prices, offers and branding
- One master menu shared across all branches — each branch can hide items or set its own price
- Every branch gets one permanent QR code — print it once, it never changes
- Customers get a fast bilingual menu (English / عربي) with tap-for-details, call and directions
- Any change in the dashboard is live on the next scan — no reprinting, ever

## The problem it solves

Paper menus are expensive and always out of date. Every price change, sold-out item or new dish means reprinting menus for every table in every branch. Simat replaces that with a single QR code per branch: print once, update forever. Prices and items change in seconds, stay in sync across branches, and customers always see the current menu in their own language.
